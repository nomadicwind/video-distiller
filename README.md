# Video Distiller

游戏操作录像蒸馏工作台。设计文档见 `docs/superpowers/specs/`，术语表见 `CONTEXT.md`。

## 运行

前置：`brew install ffmpeg uv pnpm`

    uv run --project backend uvicorn vd.api:app --port 8000   # 后端
    pnpm --dir frontend dev                                   # 前端 → http://localhost:5173

数据目录：`~/VideoDistiller`（环境变量 `VD_DATA_DIR` 覆盖；备份 = 拷贝该目录）。

## 测试

    cd backend && uv run pytest
    cd frontend && pnpm test

## LLM 后端

工作台推断功能（循环命名、方案编排）依赖 LLM 后端。支持三种形态，按优先级自动探测或通过 `VD_LLM` 显式覆盖。

| 形态 | 配置方式 | 依赖 | 备注 |
|---|---|---|---|
| **API 模式** | `ANTHROPIC_API_KEY` 环境变量 | Anthropic API 密钥 | 生产推荐；调用走 API 不需本机 claude |
| **本机 CLI 模式** | 安装并登录 `claude` CLI | `claude` 命令行工具 + 订阅额度 | 免去 API 密钥配置；每次调用有秒级延迟（claude CLI 启动时间） |
| **无后端降级** | 不配置任何后端 | 无 | 循环名称默认为「未命名循环」；方案编排单段输出确定性兜底 |

**后端解析顺序**：
1. `VD_LLM` 环境变量（若设置）：`VD_LLM=api` 强制 API 模式、`VD_LLM=claude-cli` 强制 CLI 模式、`VD_LLM=off` 禁用 LLM
2. 自动探测（VD_LLM 未设置）：检查 `ANTHROPIC_API_KEY` 存在 → API 模式；否则检查 `claude` 在 PATH → CLI 模式；都无 → 降级模式

**CLI 模式使用前提**：
- 本机已安装 claude CLI（参考 [Anthropic Claude CLI 文档](https://github.com/anthropics/anthropic-cli)）
- 已执行 `claude auth login` 并登录 Anthropic 账户
- 订阅额度允许调用（走用户已登录的订阅配额，非 API 密钥调用）
- 工作台每次命名/编排调用会启动 claude 进程（秒级延迟在正常范围，单次调用 120 秒超时）

**CI/自动化环境**：
- 后端探测不影响测试运行（测试显式注入 mock client，绝不发起真实 LLM 调用）
- CI 环境需主动设置 `VD_LLM=off` 以禁用后端探测，或配置 `ANTHROPIC_API_KEY` 且网络可用

## 标注方法论

L0（Operation）采用**人工标注红线**：标记只能来自人工标注（`provenance=human_manual`）或执行日志回灌（`provenance=execution_log`）；从视频画面推断按键序列被明确禁止（用户裁定 2026-08-21，spec §13.2）。

这一设计服务于多 Take 聚合与跨层对齐的稳健性：
- **多 Take 聚合**：同一分析的多次独立测量（Take）通过中位数与不确定度区间为每条标记产出统计鲁棒性，人工误差（打点时序抖动、视觉遮挡误读）在聚合中平滑；
- **跨层对齐校验**：L1/L2 标记与 L0 原子操作序列对齐后，能识别遗漏、重复或序列错位，强制标注质量；
- **执行日志豁免**：真实执行事件（`execution_log`）记录的键盘操作不是推断，而是观察的事实，因此以 Take 并排对比形式接纳，但不参与聚合中位数计算（维持人工标注的主体地位）。

## M7 · 人工标注体验

M7 为人工标注工作台引入完整的交互范式与快捷键生态，使标注过程从"单步操作"升级到"工作流"体验。

**核心功能**：
- **撤销 / 重做**：完整的编辑操作堆栈，恢复任意标注修改
- **AB 循环**：快速定位与重复播放，支持间隔裁整与循环清除
- **试听**：跳至标记前 400ms 播放至后 400ms 自动暂停
- **L1 参考线**：显示已标注的 L1 技能边界，辅助 L0 定位
- **实时反馈**：新标记落点闪烁动画、键帽按压反馈、状态栏最近按键与本 take 计数

**快捷键表**（所有操作支持 macOS Cmd / Windows Ctrl 模式）：

| 快捷键 | 功能 |
|--------|------|
| Cmd/Ctrl + Z | 撤销上一步操作 |
| Cmd/Ctrl + Shift + Z | 重做下一步操作 |
| I | 设置 AB 循环入点 |
| O | 设置 AB 循环出点 |
| L | 开启/关闭 AB 循环 |
| Shift + L | 清除 AB 循环标记 |
| P | 试听选中标记（前后各 400ms，自动暂停） |
| R | 显示/隐藏 L1 参考线 |

> 注：录入模式开启且在 L0 泳道时，字母/数字键一律作为打点（含表中 I/O/L/P/R/E/T/A/S）；需先退出录入模式再使用这些快捷键。

### 组合键录入

L0 泳道录入支持**组合键**——将修饰键（Ctrl、Alt、Shift）与数字/字母组合，作为单条标记记录。支持两条路径：

**键盘输入**：`Ctrl+2`、`Alt+Q`、`Shift+3` 等按键组合在录入模式下自动识别，标记标签采用规范序（Ctrl → Alt → Shift），与物理按下顺序无关。该模式使用 `e.code`（物理键位）而非 `e.key`（字形值），所以非 QWERTY 键盘布局亦正确对应数字/字母（如 Dvorak 键盘的物理 Digit0-9、KeyA-Z 位置）。**注**：Cmd/Meta 键不参与组合。键位表（键位设置页）中的组合键字符串需按同一规范序（Ctrl → Alt → Shift → 基键）书写，与录入生成的标签逐字一致——顺序不一致时对齐不会链接，而是以三方冲突形式呈现。

**面板粘滞修饰**：Entry Panel 键帽区顶部有三枚修饰芯片（Ctrl、Alt、Shift）。点亮任意组合后点击基础键帽（含 LMB/RMB/Wheel），合成单条标记并自动清空点亮；空标记不受修饰影响。完全不激活键盘即可完成输入——适合需要高精度、低干扰的标注场景。
*（自 M10 起，打点入口已移至时间轴打点条。）*

## M9 · 标记列表与最小间距

M9 为标注工作台引入标记列表面板与最小间距校验，进一步提升标注精度与效率。

**最小间距规则**：同一 Take 内两条标记的时间间距不得小于一帧（1000/fps 毫秒，默认 fps=30 即 ~33.33ms），服务端拒绝（HTTP 400）。前端在发送请求前进行温和预检提示，不会因间距不足而发出请求。执行日志回灌（`provenance=execution_log`）豁免此规则——真实执行事件（如和弦同帧按下）作为观察事实接纳。规则设计基于 ±1 帧的测量精度；既有数据不追溯。

**标注面板改版**：
- **泳道选择**：从独立卡片移入时间轴沟槽，减少面板占用。
- **标记列表**：选定泳道的当前 Take 标记按时序排列，每行显示时码（`HH:MM.mmm`）/ 类型徽章（"打点" 或 "空标记"）/ 标签 / 按住锁形（仅 `end_ms != null` 时）。点击列表行 = 选中标记 + 跳转播放头，与时间轴双向同步。
- **内联编辑**：选中行展开编辑器，支持：
  - **标签改名**：文字输入，L1/L2 提供已用标签建议（datalist），L0 不提供；Enter/失焦提交。
  - **时刻调整**：毫秒数字输入，含预检（同 moveMark）；`[−1帧]` / `[+1帧]` 按钮快速调整；Enter/失焦提交。
  - **解除按住**：点击「解除按住」按钮，直接清除 `end_ms`。
  - **删除标记**：点击删除按钮移除。
  - **全部可撤销**：所有编辑操作支持 Cmd/Ctrl+Z 撤销和 Cmd/Ctrl+Shift+Z 重做。
*（自 M10 起，标注面板已升级为序列视图，打点入口已移至时间轴打点条。）*

## M10 · 序列视图与打点条

M10 将打点入口下沉为时间轴面板内的紧凑"打点条"，右侧标注面板升级为"序列视图"，进一步优化标注工作流与时间轴密度。

**打点条（Entry Strip）**：位于时间轴面板内、工具栏之下标尺之上的 34px 紧凑单行条。泳道选中时显示，无泳道选中时隐藏。

- **L0 泳道**：显示录入模式 Switch、三枚修饰芯片（Ctrl/Alt/Shift）、数字/字母/功能键键帽、LMB/RMB/Wheel、空标记。修饰芯片点亮任意组合后点击键帽自动合成组合键标记并清空；空标记不受修饰影响。完全不激活键盘即可完成输入——高精度、低干扰的标注体验。
- **L1/L2 泳道**：显示技能名输入框与插入按钮，支持 datalist 建议。

**序列视图（Sequence View）**：右侧标注页签由 M9 的标记列表升级为序列视图，进一步强化时序感知。页签顶部为 take 行（chips/新 Take/聚合 Switch），下方为序列视图列表（flex:1 滚动）。

- **竖轨与节点**：列表左侧 2px 竖轨贯穿所有标记；每行节点为 8px 实心圆点（泳道色；`kind=release` 空标记时为空心圆）。
- **行间 Δ 间隔**：相邻两条标记之间在竖轨侧显示时间差 `+{delta}ms`（单位 ms，如 `+2500ms`），增强操作序列的时序感知。
- **标签与类型**：时码用 mono 字体；标签渲染为 inert Keycap 风格小帽，支持显示完整组合键字符串。
- **按住指示**：`end_ms != null` 的标记下方附着按住区段条（泳道色低透圆角条）与 `按住 XXXms` 标注。
- **内联编辑**：选中行展开编辑器，M9 四项功能（标签改名、时刻调整、解除按住、删除）+ 完整的撤销/重做支持，逻辑沿用 M9 不动。

## M11 · 拖动定位与监视器

M11 把时间轴从"标尺可点"扩展为"全表面可 scrub"，并让缩略图带、时间轴面板高度、监视器全屏三处交互更贴近专业剪辑器手感。

- **全表面 scrub**：标尺原有的 pointerdown 立即 seek（帧取整 clamp）+ 指针捕获连续拖动语义，扩展到泳道内容区空白（含未选中泳道——点击即选中该泳道并同一手势内定位）；沟槽列（泳道头）保持纯选择语义，不触发 scrub。命中优先级不变：Δ 药丸 > 标记 > 空白 scrub。
- **缩略图带全长 scrubber**：ThumbStrip 支持与标尺一致的点击/拖动 scrub，悬停与拖动时显示跟随光标的时码气泡，并有一条随播放头位置移动的针线。
- **默认视口 = 全长**：打开分析时时间轴初始视口即整段时长（等价于打开即"适配全长"），不再是固定 10 秒窗口。
- **分割条**：位于缩略图带与时间轴面板之间的 6px 分割条，拖动可调整时间轴面板高度（`cursor: row-resize`），高度经上下限 clamp；双击复位为内容自适应高度；调整结果持久化到本地（下次打开同一浏览器时保留）。时间轴面板被拖矮到小于内容自然高度时，画布区域内部纵向滚动，不影响整体无页面滚动的框架。
- **监视器全屏**：Transport 右端的按钮（Maximize 图标）或双击监视器画面均可进入/退出全屏；退出沿用浏览器原生 Esc，未新增快捷键。

## M12 · 对比模式

M12 为监视器引入并排对比模式，支持在同一份分析里选另一支已就绪的视频作为参照，核对同一段操作在不同录像间的执行差异。

- **分栏监视器**：开启对比且已配置对比视频时，监视器分为左右两格（各占一半，`object-fit: contain`）：左格为主视频（A，行为与快捷键完全不变），右格为对比视频（B，恒定静音、无原生播放控件）。关闭对比时监视器 DOM 与 M11 完全一致（不渲染分栏包装）。全屏仍作用于整个监视器容器，双画面一起进出全屏。
- **偏移语义**：`tB = tA + offset_ms` 是唯一驱动关系，B 的位置永远由 A 的播放头单向推导，B 端任何操作都不会反向驱动 A。`tB` 落在 B 的时长范围之外时，B 暂停并显示「超出对比视频范围」遮罩，不会 clamp 到端点画面冒充已同步。播放中每次主播放头更新都按 80ms 阈值判定漂移，超出则硬回写 B 的播放位置；暂停态下的 seek 直接精确同步。B 的倍速跟随 A。
- **校准**：进入校准态时 B 暂时脱离跟随（主视频同时暂停，避免边跑边校），B 格下沿出现独立定位条——点击/拖动直接 seek B、`[−1帧][+1帧]` 按 B 自身 fps 步进、mono 时码实时显示。两侧各自停在同一动作瞬间后点击「以当前两帧对齐」，把当前两侧的时间差保存为新偏移并退出校准，B 恢复跟随。
- **对比条**：位于 Transport 之下的独立一行，可开关对比、下拉选择就绪视频（含「清除对比」）、进入/退出校准、直接编辑偏移 ms（`[−1帧][+1帧]` 按 A 自身 fps 微调，与校准定位条按 B fps 步进是两件独立的事）、实时显示 B 的时码。未配置对比视频时点击 Switch 只做引导提示，不会静默失败。
- **持久化**：对比视频与偏移保存在 Analysis 上（`PATCH /api/analyses/{id}/compare`，`video_id: null` 清除对比并连带清空偏移），刷新页面后配置仍在；选定的视频必须处于 `ready` 状态。
