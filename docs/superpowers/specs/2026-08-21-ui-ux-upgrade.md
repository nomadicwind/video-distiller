# Video Distiller UI/UX 升级设计规格（M5）

> 功能不变约束：本升级不改任何后端行为与数据模型；前端 API 消费面不变（可新增对既有路由的调用，如拖动标记复用 PATCH /marks）。所有既有测试保持绿。

## 1. 对标选择

**主对标：剪映专业版（CapCut Desktop）** —— 理由：现代深色专业剪辑 UI 的当前标杆；面向中文创作者，交互习惯与本产品用户重合；三区布局（素材/预览/属性 + 底部时间轴）与本系统信息结构同构；视觉上兼具专业密度与亲和度。
**辅对标：DaVinci Resolve** —— 时间轴密度、标尺/吸附/多轨道语义、专业时码呈现。

采纳的设计范式：
- 全局深色三层底色体系（应用底 → 面板 → 悬浮控件），面板间用缝隙而非线框分区
- 中央监视器 + 其下集成传输条（图标按钮 + 大时码）
- 底部通栏时间轴面板：自带工具栏（吸附、缩放、模式提示）、左侧轨道头沟槽、顶部可点击标尺
- 右侧检查器（Inspector）用页签分组，而非纵向堆叠一切
- 单一强调色 + 每轨道色相；键位以"键帽"样式呈现

## 2. 设计令牌（styles/tokens.css，全局唯一色值来源）

```css
:root {
  /* 底色三层 */
  --bg-app: #0d0e12;        /* 应用底 */
  --bg-panel: #16181e;      /* 面板 */
  --bg-elevated: #1d2027;   /* 卡片/悬浮 */
  --bg-control: #262a33;    /* 控件底 */
  --bg-control-hover: #313743;
  --bg-inset: #101216;      /* 时间轴/监视器内嵌底 */
  /* 边界 */
  --border: #2a2e38;
  --border-subtle: #21242c;
  /* 文字 */
  --text-1: #f2f4f8;
  --text-2: #a8afbd;
  --text-3: #6b7280;
  /* 语义色 */
  --accent: #5b8cff;
  --accent-soft: rgba(91, 140, 255, 0.14);
  --success: #34d399;
  --warn: #fbbf24;
  --danger: #f87171;
  --selection: #ffd54a;     /* 选中标记（沿用既有黄） */
  /* 轨道色相 */
  --lane-l0: #38bdf8;
  --lane-l1: #a78bfa;
  --lane-l2: #f472b6;
  /* 形状 */
  --radius-s: 6px; --radius-m: 8px; --radius-l: 12px;
  --shadow-1: 0 1px 2px rgba(0,0,0,.4);
  --shadow-2: 0 8px 24px rgba(0,0,0,.5);
  /* 字体 */
```

规则：组件内禁止硬编码色值；时码与毫秒数一律 `--font-mono` + `font-variant-numeric: tabular-nums`。

## 3. UI 组件套件（frontend/src/ui/）

| 组件 | 变体 | 要点 |
|---|---|---|
| Button | primary / ghost / danger / icon | 高度 28（工具栏 24）；primary 填充 accent；ghost 透明+hover 提亮；icon 方形含 lucide 图标；disabled 40% 透明；focus-visible 外圈 accent |
| Keycap | — | 键帽样式：--bg-control 底、1px 顶部高光、下沿 2px 深色、圆角 6、mono 字体；按下微陷动画 |
| Tabs | — | Inspector 用；底部 2px accent 指示条 |
| Card | — | --bg-elevated + radius-l + shadow-1；标题行 + 内容 |
| Badge | accent/success/warn/danger/neutral | 状态徽章（ready/processing/failed、已接受/已拒绝/待裁决） |
| Field | — | label + 输入统一样式（输入框 --bg-inset、1px border、focus accent） |
| Tooltip | — | CSS-only（data-tip 属性 + ::after），延时 400ms |
| EmptyState | — | 图标 + 一句话 + 主操作按钮 |

图标：`lucide-react`（唯一新依赖，tree-shaken）。

## 4. 应用外壳

- **TopBar（全局，48px）**：左 = 产品标识（Distiller 字标 + 图标）；中 = 主导航页签（资料库 / 技能目录 / 键位 / 循环与方案 / 执行台）；右 = 当前上下文（工作台时显示分析名 + 键位选择器）。取代现在每页各自的返回按钮 + 库页按钮堆。工作台仍保留 ← 返回（TopBar 左侧上下文位）。
- **StatusBar（工作台底部，24px）**：左 = 当前工具/模式提示（如"录入模式 · 敲键即打点"）；中 = 快捷键提示精简条；右 = 帧率 / 时长。`?` 打开完整快捷键浮层。

## 5. 工作台（核心屏）

布局（CSS grid，间隙 1px 用 --bg-app 作缝）：

```
┌────────────────────────────────────────┬──────────────┐
│  监视器（视频，居中，黑底）             │  Inspector    │
│  传输条（播放/逐帧/速度/大时码/打表）    │  [标注][推断] │
│  缩略图带                              │              │
├────────────────────────────────────────┴──────────────┤
│  时间轴面板（通栏）：工具栏 + 标尺 + 轨道                │
├───────────────────────────────────────────────────────┤
│  StatusBar                                             │
└───────────────────────────────────────────────────────┘
```

### 5.1 传输条

图标按钮组（lucide）：跳到开头 | 上一帧 | 播放/暂停（大） | 下一帧 | 循环预留位；速度下拉（0.25/0.5/1/2×）；中央大时码 `00:00:00.000`（mono 20px）+ 右侧灰色总时长；右端：打表按钮（T）+ 打表计数 + 清空（Tally 融入传输条，TallyBar 独立组件消失）。所有按钮 tooltip 含快捷键。

### 5.2 Inspector

**标注页签**：
- 轨道选择：三张横向排列的轨道卡（L0 操作 / L1 技能 / L2 连招），选中卡 = 轨道色左边条 + accent 边框 + 提亮底；卡上显示 take 数。与时间轴轨道选择双向同步（同一状态）。
- Take 段：chip 行（#1…#n，当前 = accent 填充），+ 新 Take ghost 按钮；聚合开关（A）。
- L0 打点：键帽网格（Keycap 组件），标题行"在播放头处打点"；录入模式 = Switch 样式开关 + 状态说明；空标记单独一行。
- L1/L2：技能名输入（datalist 保留）+ 插入按钮（primary）。
**推断页签**：运行对齐 / 发现循环 / 编排方案 三按钮成组；提案卡重做（见 §7）。

## 6. 时间轴重设计（本升级的核心）

### 6.1 结构

- **工具栏（28px）**：左 = 吸附开关（磁铁图标，默认开，快捷键 S）+ 当前模式提示；右 = 缩放 −/滑杆/+、适配全长按钮。
- **标尺（28px）**：主刻度 + 次刻度（间隔由 niceTickInterval(spanMs) 计算：1/2/5×10^n ms 序列，目标主刻度间距 ≥80px），主刻度下标时码（mono 10px --text-3）；底部 1px border。
- **轨道头沟槽（左侧 112px 固定）**：每轨一格：轨道色圆点 + 层名（L0/L1/L2）+ 副标（操作/技能/连招）+ take 计数徽章。选中轨：沟槽格左侧 3px 轨道色条 + 底色 --accent-soft + 层名 --text-1（未选中 --text-3）。
- **轨道行（每轨 72px）**：选中轨整行底色 rgba(accent, 0.06)，未选中透明；行间 1px --border-subtle。
- **播放头**：全高 1.5px 白线；标尺内倒三角手柄（accent 填充）；手柄旁时码气泡（黑底白字 mono，仅拖动/悬停时显示）。
- **打表 marker**：标尺内琥珀色小旗（替代现有三角）。

### 6.2 标记与区间视觉

- input 标记：轨道色相实心圆（r=5），标签白字置于圆点上方 8px 的深色小药丸内（超出视口裁剪）；release（空标记）：同尺寸空心圆。
- 选中标记：--selection 色 + 外圈光晕（r=7 + 2px ring）；hover：r=6 + pointer + tooltip（标签 + 时码）。
- 区间：两标记间中点显示 `Δ123ms` 药丸（mono 10px）；holding 区间 = 两标记之间的圆角横条（轨道色 32% 透明，高 14px）+ 药丸内前缀锁形小图标；holding 切换 = 点击 Δ 药丸整体（热区 ≥ 18×18，替代现有 10×10 checkbox）。
- 幽灵 Take（非当前 take 的标记）：轨底 6px 半透明刻度，色相同轨道色 25% 透明（现为灰色）。
- 聚合叠加：IQR 带 = success 32% 圆角条；少数派 = warn 竖条；样式提亮但语义不变。

### 6.3 交互语义（修复"打标从哪操作/对齐繁琐"的核心）

| 手势 | 语义 |
|---|---|
| 点击标尺 / 拖动标尺 | 播放头 seek 到该处（按帧取整）——直接对齐，不再依赖逐帧键逼近 |
| 点击轨道空白处 | 若该轨未选中：选中该轨；若已选中：**播放头 seek 到点击处**（按帧取整） |
| 点击标记 | 选中 + seek 到标记 |
| 拖动标记 | 移动标记（实时预览 + Δ 显示，松手 PATCH t_ms；按帧吸附；吸附开时对打表 marker/相邻标记 ±6px 吸附） |
| 拖动播放头手柄 | 连续 scrub |
| 滚轮 | 平移；Ctrl/⌘+滚轮 | 缩放（焦点在光标处） |
| 悬停轨道 | 光标处幽灵竖线 + 标尺气泡显示光标时码（打点前所见即所得） |
| 点击 Δ 药丸 | 切换 holding |

打点主流程明示化：光标悬停即见幽灵线与时码 → 点击定位播放头 → 键帽/键盘打点落在播放头 → 状态栏常驻提示"点击时间轴定位 · 键帽或录入模式打点"。

### 6.4 纯函数约定

`niceTickInterval(spanMs, widthPx): { majorMs, minorMs }`、`snapMs(rawMs, fps, magnets: number[], tolPx, viewport): number` 进 layout.ts，vitest 覆盖。

## 7. 其余各屏

- **资料库**：上传区 = 虚线拖放框（点击/拖入均可）+ B 站 URL 行合并为一张"导入"卡；视频列表 = 网格卡片（缩略图占位 = 首帧 sprite 若有，否则渐变底 + 影片图标；状态 Badge；打开为 primary）。
- **技能目录 / 键位设置**：表格统一样式（表头 --text-3 小写间距、行 hover 提亮、斑马纹弱化）；表单入 Card；键位绑定值用 Keycap 呈现。
- **循环与方案**：两段卡片列表；导出链接 = 图标按钮组（MD/AHK/PLAN/RZR 小徽章）；编辑 primary。
- **方案编辑器**：左编辑列 + 右预览列（sticky）；段落卡 = Card；块行 = 拖柄图标 + 类型徽章 + 控件；预览 <pre> 深内嵌底 + mono；版本区含当前版本徽章。
- **执行台**：控制按钮 = 图标+文字组合（开始 primary、停止 danger）；状态 = 大 Badge + 进度条（cursor/total）；日志 = 深底表格式滚动区（mono）；警告/手动循环 = warn Card。
- **ErrorBar**：右下角 toast 叠层（danger 底、自动 8s 消退、可点关）。替代顶部横条。

## 8. 用户操作路径审查结论（UX 修复清单）

| # | 路径 | 现状问题 | 修复 |
|---|---|---|---|
| 1 | 选轨 | 高亮仅 11px 标签变色 | §6.1 三重高亮（沟槽条+行底色+卡片态）+ Inspector 轨道卡同步 |
| 2 | 打点定位 | 需 [ ] 逐帧逼近，点击时间轴不动播放头 | 标尺/轨道点击与拖动 seek + 悬停幽灵线 + 帧吸附 |
| 3 | 打点入口 | 键帽区无说明，录入模式藏在长文案 checkbox | 键帽标题"在播放头处打点"+ Switch + 状态栏模式提示 |
| 4 | 移动标记 | 仅 , . 键 ±10ms，不可拖 | 拖动标记 + 吸附 + 实时 Δ |
| 5 | holding | 10px 画布 checkbox 难点中 | Δ 药丸整体为开关（≥18px 热区） |
| 6 | 缩放 | 仅 Ctrl+滚轮，无提示 | 工具栏缩放控件 + 适配全长 + 快捷键提示 |
| 7 | 快捷键发现 | 无任何提示面 | 按钮 tooltip 标注快捷键 + StatusBar 精简条 + ? 浮层 |
| 8 | 提案噪声 | 原始错误 JSON 整段进卡片 | 错误折叠为 warn Badge + tooltip 详情；卡片信息层级重排 |
| 9 | 全局导航 | 每页自带返回/按钮堆 | TopBar 常驻导航 |
| 10 | 状态可见性 | 转码中仅文字 status | Badge + 卡片进度态；执行台进度条 |

## 9. 验收标准

1. 视觉：七屏全部脱离浏览器默认控件样式；令牌全覆盖（grep 组件目录无裸 hex，除 tokens.css）；1280×800 与 1600×900 布局不破。
2. UX：§8 表 10 项逐条可演示；两条原始抱怨路径（选轨可见性、点击对齐打点）用前后对比截图记录于 README。
3. 功能稳定：后端 169 测试不动且不需重启适配；前端既有 38 测试保持绿 + 新增 layout 纯函数测试；构建体积增量 < 120KB gzip。
4. 性能：时间轴 60fps 交互（拖动/缩放无可感卡顿，requestAnimationFrame 节流重绘）。
