# M14 全项目 UI 重设计（墨金武侠·影调暗色）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `design-system/MASTER.md`（用户裁定方向 A：墨金武侠·影调暗色）对全部七个页面做视觉重设计，并同轮修复 2026-09-29 评审中 UI 形态的体验缺陷（推断就绪引导、键位页列表化、录入 Esc 出口、对比 B 加载错误态、上传进度、空态/确认/响应式）。**纯前端**：后端零改动（199 测试终验证明）。

**Architecture:** 令牌先行——tokens.css 是唯一色值/字体真源，全部组件经语义令牌换肤（timeline 画布经既有 theme.ts getComputedStyle 缓存自动继承）；四任务自底向上：①令牌+ui 套件+壳层（全局皮肤），②工作台精修+录入 Esc+对比错误态，③键位/技能/推断三页重构（列表化、pattern 构建器、就绪引导），④资料库/循环/执行台/编辑器+文档截图。

**Tech Stack:** 既有栈，零新依赖（字体走 Google Fonts @import + 完整系统回退，离线不劣化布局）。

**Spec:** `design-system/MASTER.md` 为视觉契约（色值/字体/形态/交互语言逐条约束）；本计划 Global Constraints 为行为契约。

## Global Constraints

- **后端零改动**；**功能语义零回归**：打点/scrub/吸附/撤销/AB 循环/试听/对比同步/推断/导出全部行为不变，前端既有 161 测试不改断言只增
- **令牌纪律**：色值/字体只进 tokens.css；组件禁裸 hex；MASTER.md 表格与 tokens.css 字段一一对应，实现若需微调色值，改两处并在报告说明
- **对比度红线**：正文/主文 ≥4.5:1、次文与图标 ≥3:1（MASTER 色板已验算，实现不得擅自降对比）；功能色必配图标/文字
- **辉光配额**：金色辉光仅播放头针线、录入激活键帽、选中泳道头三处，各 ≤ 0 0 10px @20%；prefers-reduced-motion 下全部动画/辉光过渡归零
- **字体离线红线**：@import + font-display swap；系统回退栈（PingFang SC/微软雅黑/宋体族）必须完整可用——断网首屏无 FOIT、无布局跳动（标题行高按回退字体预留）
- **UX 修复清单（本轮承诺，均纯前端）**：①推断页就绪引导卡（键位是否绑定/L0 标注数/键位表对 L0 标签的覆盖数，未就绪项给跳转指引；数据全部来自既有 GET 接口与 store）②键位页以 GET /api/keymaps 列表替代凭记忆输 id + 重复技能绑定行警告 + 空态 ③录入模式 Esc 退出（hotkeys 早于录入分支）+ 浮层对 E 键陷阱的脚注更正 ④对比 B video onError → 遮罩变体「对比视频加载失败」⑤上传进度（XHR onprogress 百分比，退化为不定进度条）⑥全站空态=说明+行动、破坏性操作确认对话框（现有删除技能）、toast 3-5s ⑦≤900px 顶栏导航不折行（紧凑模式），100vh 无滚动框架保持
- 100vh 无页滚动双查 1280×800 / 1440×860；900px 宽降级不破版（允许水平滚动出现在时间轴内容而非页面）
- 每任务 `cd frontend && pnpm build && pnpm test` 全绿；浏览器自查**纯鼠标**（严禁触发键盘录入——用户真实标注数据在库，历史四次污染教训）且不改动任何用户数据（video-3 的 L0 11 条/L1 7 条/L2 2 条、对比偏移 4827ms 是基线，自查后核对不变）
- conventional commit + 尾注 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`
